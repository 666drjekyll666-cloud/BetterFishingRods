# Deferred Balance Concept

The earlier Better Fishing Rods balance concept (x2/x3 catches, faster bites, and longer hook windows for higher-tier rods) is **not part of the current 1.x product**.

The released 1.x scope is intentionally visual-only: it adds the bobber countdown ring without changing fishing balance.

If rod-balance changes are revisited later, treat them as a separate product decision and re-run the relevant balance/runtime acceptance gates before implementation.

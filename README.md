# Bite Countdown

A small visual quality-of-life mod for **Graveyard Keeper 1.407**.

**Bite Countdown adds a subtle shrinking ring around the bobber so you can see when the next bite is coming.**

The ring follows the game's real waiting time and reaches the bobber at the native bite moment.

## What it changes

- Adds an in-world countdown ring around the bobber.
- Follows the full native bite-wait interval.
- Appears again if you miss a hook and vanilla starts another wait.

## What it does not change

- no faster bites;
- no longer hook window;
- no extra fish;
- no changes to fish selection, rarity, quality, bait, energy, or the reeling minigame.

The game still owns the fishing result. Bite Countdown only visualizes the waiting phase.

## Installation

1. Install BepInEx 5 for Graveyard Keeper.
2. Put `BiteCountdown.dll` into `Graveyard Keeper/BepInEx/plugins/`.
3. Start the game.

No configuration is required.

## Compatibility

Targeted and tested against **Graveyard Keeper 1.407**.

The mod stores no custom save data. Removing `BiteCountdown.dll` restores vanilla behavior without save migration.
